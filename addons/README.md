# Modules Odoo spécifiques

Modules `eguitra_*` du noyau (API métier, axes analytiques, moteur d'approbation, contrôles de clôture).
Montés dans le conteneur sous `/mnt/extra-addons`, en tête de `addons_path`.
Les modules OCA ne sont pas copiés ici : ils sont récupérés aux commits épinglés par `infra/oca/fetch.sh`.
